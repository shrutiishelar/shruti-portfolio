# Shruti Kishor Shelar — Premium Interactive Portfolio

A responsive Next.js + React portfolio with Framer Motion animations, filterable project cards, animated monogram hero, skill sections, education timeline, and contact links. All portfolio content is based on the uploaded resume.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the project folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Visit http://localhost:3000

## Deploy
Push the folder to GitHub and import the repository into Vercel. Vercel detects Next.js automatically.

## Personalize later
The hero currently uses animated `SS` initials instead of a portrait. Add a photo later if desired.
